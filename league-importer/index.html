Public leagues work directly. Private leagues need two values from your own ESPN session (SWID and espn_s2) — check "This is a private league" below for where to find them. Since this relies on ESPN's undocumented API, it could occasionally change or break without warning.
Paste your league's URL directly (we'll pull the ID out of it), or just the number after leagueId=, e.g. fantasy.espn.com/football/team?leagueId=123456
Found in your browser's cookies for espn.com — right-click the ESPN page → Inspect → Application (or Storage) tab → Cookies → espn.com → look for SWID and espn_s2. These are sent to a small proxy we run (needed because browsers block sending cookies to ESPN directly) and are never stored anywhere.

Data sources: Sleeper's public API (rosters, no login, both football and basketball) and ESPN's undocumented fantasy API (read-only, football only for now; no login for public leagues; private leagues proxied through a small Cloudflare Worker, no credentials ever stored). None of these integrations are officially supported, so any could change or break without notice. Pun data is pulled live from the site's own database each time this page loads, so it's always current.
