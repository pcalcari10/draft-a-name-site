ESPN League Importer

Enter your ESPN league ID to pull a roster and see every pun we have for each player — plus team-pride names for whichever franchises are on your roster. Nothing is uploaded anywhere.

Public leagues only. ESPN doesn't provide an official API, and private leagues require credentials this browser-based tool can't securely handle. If your league is set to private, this won't be able to reach it — try the Sleeper importer instead if you use that platform too. Since this relies on ESPN's undocumented API, it could occasionally break without warning.
Find this in your league's URL — it's the number after leagueId=, e.g. fantasy.espn.com/football/team?leagueId=123456
