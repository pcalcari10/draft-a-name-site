Sleeper Roster Importer

Enter a Sleeper username to find your leagues, pull a roster, and see every pun we have for each player — plus team-pride names for whichever franchises are on your roster. Nothing is uploaded anywhere.

Data sources: api.sleeper.app (rosters, public, no login) and dynastyprocess/data on GitHub (Sleeper player-ID → name mapping, updated weekly). The pun database embedded in this file is a snapshot from when it was built — ask for a refreshed copy after a big batch of new puns.
